# Game Objects & Components Reference

This document describes the structure of game entities, component lifecycles, and common components used in the Word Online game server.

---

## GameObject

The central entity container class is [GameObject.java](file:///Users/jeong-yunseong/development/word-online/dev/game-server/src/main/java/com/wordonline/server/game/domain/object/GameObject.java). Every interactive object in the game (players, projectiles, structures, traps, elements) is a `GameObject`.

### Properties
- **`id`**: Unique integer generated by a global atomic counter (`idCounter`). Used for tracking and network synchronization.
- **`master`**: Enum (`LeftPlayer`, `RightPlayer`, `None`). Defines which player owns the object (dictates damage logic, targeting, etc.).
- **`type`**: [PrefabType](file:///Users/jeong-yunseong/development/word-online/dev/game-server/src/main/java/com/wordonline/server/game/domain/object/prefab/PrefabType.java) enum defining the object template.
- **`status`**: Current action state (`Initializing`, `Idle`, `Attack`, `Damaged`, `Destroyed`).
- **`position`**: A `Vector3` spatial coordinate. If a position changes beyond the boundaries (`GameConfig.X_BOUND` or `GameConfig.Y_BOUND`), the object is automatically destroyed.
- **`element`**: Elements associated with the object (e.g. FIRE, WATER, NATURE, ROCK, LIGHTNING, WIND) which determine damage multipliers.
- **Component lists**:
  - `components`: active components updated per tick.
  - `componentsToAdd` & `componentsToRemove`: modification queues processed safely at the end of the tick.
  - `colliders`: registered spatial shapes.

### Lifecycle Hooks
1. **Creation**:
   - `new GameObject(...)` triggers `gameContext.createGameObject(...)`.
   - `ObjectsInfoDtoBuilder` registers the creation, pushes it to `gameObjectsToAdd` buffer, and executes `gameObject.start()`.
2. **Initialization (`start()`)**:
   - Locates the `PrefabInitializer` using `PrefabProvider.get(type)`.
   - Populates the game object with default colliders and components.
   - Flushes initial components and executes `start()` on them.
   - Sets the state to `Status.Idle`.
3. **Tick Update (`update()`)**:
   - Loop ticks: invokes `update()` on all active components.
4. **Destruction (`destroy()`)**:
   - Marks status as `Status.Destroyed`.
   - Invokes `onDestroy()` on all components.
   - Removed from active arrays in the next `GameObjectAddRemoteSystem` flush.

## Component

All behavioral classes inherit from the abstract class [Component.java](file:///Users/jeong-yunseong/development/word-online/dev/game-server/src/main/java/com/wordonline/server/game/domain/object/component/Component.java).

```java
public abstract class Component {
    public final GameObject gameObject;

    public abstract void start();
    public abstract void update();
    public abstract void onDestroy();
}
```

### Common Core Components

- **`RigidBody`**:
  - Located at: [RigidBody.java](file:///Users/jeong-yunseong/development/word-online/dev/game-server/src/main/java/com/wordonline/server/game/domain/object/component/physic/RigidBody.java).
  - Handles velocity calculations, acceleration, mass, and applying velocities to the parent GameObject's position.
- **`Collider`**:
  - Bounding volumes (e.g. `CircleCollider`) for spatial queries.
- **`Mob`**:
  - Base component for objects that have health bars and take damage.
- **`Drop`**:
  - Located at: [Drop.java](file:///Users/jeong-yunseong/development/word-online/dev/game-server/src/main/java/com/wordonline/server/game/domain/object/component/magic/Drop.java).
  - Component that models objects falling along the Z axis (gravity simulation) and destroying themselves on collision with damageables.
- **`Shot`**:
  - Located at: [Shot.java](file:///Users/jeong-yunseong/development/word-online/dev/game-server/src/main/java/com/wordonline/server/game/domain/object/component/magic/Shot.java).
  - Linear projectile movement that triggers an area-of-effect explosion on contact.
